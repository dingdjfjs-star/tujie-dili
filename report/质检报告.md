## 三、设计决策留痕

- **不做「API 失败自动回退示例」**：上传的是用户自己的图，回落到固定示例会张冠李戴；改为明确报错（HTTP 状态 + 中文原因 + 排查提示），演示体验走内置示例入口。
- **演示数据诚实标注**：示例报告页挂「演示数据 · 内置示例」红章横幅，示例卡区与 AI 状态卡均有说明，与工作区「明确标注演示数据」的惯例一致。
- **配额降级优先保文字**：localStorage 吃紧时先丢全部图片缩略图、保留全部解析文本与错题，再按「最旧非收藏优先」淘汰。
- **密钥零出域**：仅存本机 localStorage，仅随解析请求发往用户自填接口；导出 JSON 不含密钥（有断言把关）。
- **v1.1 丰富化的边界**：锦囊/统计/计分全部由本地数据驱动（按日期轮换、localStorage 统计），零接口零外部依赖；分章渲染对「AI 不按五段结构输出」的报告优雅降级（切不出章节时整体渲染原文）。

## 四、已知边界

- AI 解析质量取决于所选多模态模型对地理图形的理解能力；提示词已约束「严格基于图表本身，不编造图中没有的信息」，但对复杂地图册整页图建议配合「图表类型提示」使用。
- 浏览器直连 API 依赖接口方允许跨域（智谱实测可用）；若遇 CORS 拦截，换用支持 CORS 的端点即可，页面逻辑无需改动。
- localStorage 50 条上限内含图片约可存 15~30 条；重度使用建议定期「导出 JSON」备份。
