一、这个项目是什么

把中学地理课本里任意一张图表（等高线图 / 气候直方图 / 洋流图 / 统计图）拍照上传，多模态大模型（默认智谱 GLM-4V-Flash）按教材与课标输出五段式教研报告：图表基本信息 → 核心要素识别 → 规律原理 → 考点易错 → 三道变式题。

报告不是"看完就走"的文本——引擎把它切成分章卡片、章节导览芯片和可作答的自测题；答错自动进错题本，错题可"举一反三"再生成同类题；整份报告可一键生成分享卡长图。

成品三看：线上 dingdjfjs-star.github.io/tujie-dili ｜ node test\test.js → 285 项断言全绿 ｜ 最惊艳的点：自由 Markdown → 结构化交互的转换（见第五节组件 4）。

先自己动手：下面每个"试一试"组件调用的都是项目真实源码——改输入，看输出。

二、设计逻辑：五个"为什么不"

决策点选了什么不这样做的后果
AI 失败怎么办报错 + 独立示例入口，不回落到固定示例示例报告与用户图片对不上，等于教学生看假报告
Markdown 渲染自研 130 行"先全量转义、再拼装标签"第三方库默认信任 HTML → AI 输出里的注入活下来
题池抽题mulberry32 种子 PRNG（day + 错题特征）Math.random 不可复现 → 质检无法断言、复习对不上
配额降级顺序先弃图片 → 再弃旧记录 → 最后弃到剩当前一条顺序反了：学习文字资产先没（测试抓出的真 bug）
提示词五段契约结构逐句写进自动化断言改提示词时契约被无声破坏，下游解析器少卡少题
数据流一句话记：上传图 → 压缩 → 多模态 API（无 Key 走示例）→ 引擎拆解（分章/拆题/提标签）→ 交互消费（卡片/自测/错题本/举一反三/分享卡）。

四、核心代码逐段精讲（配复制按钮）

4.1 报告拆解：自由文本 → 可交互结构（js/engine.js:6 / 102）

不要求 AI 输出 JSON（小模型格式漂移严重），而是约定五段标题契约，正则按锚点切片；解析失败整体降级为原文渲染。

function splitReport(md) {
  var text = String(md || '').replace(/\r\n/g, '\n');
  var m = text.match(/^##\s*[五伍5]\s*[、.．:：]?\s*变式/m);   // 找"第五节"锚点
  if (m && typeof m.index === 'number') {
    return { main: text.slice(0, m.index).trim(),      // 一~四节正文
             quizText: text.slice(m.index).trim() };   // 变式题段
  }
  return { main: text.trim(), quizText: '' };            // 无五节 → 整体当正文
}
坑：splitSections 返回的是对象 {preamble, sections}，UI 层曾把它当数组 .map → 整页白屏（bug #5）。解析器有测试 ≠ UI 接线没错，两道关都要在。

4.2 转义优先渲染器（js/md.js:5 / 28）

function escapeHtml(s) {
  return String(s)
    .replace(/&/g,'&amp;').replace(/</g,'&lt;')
    .replace(/>/g,'&gt;').replace(/"/g,'&quot;');
}
function inline(s) {
  s = escapeHtml(s);                                  // ①先全量转义
  s = s.replace(/`([^`]+)`/g, '<code>$1</code>');  // ②再拼自家标签
  s = s.replace(/\*\*([^*]+)\*\*/g, '<strong>$1</strong>');
  return s;                                           // 文本里的任何标签都已是实体
}
中文有序列表与数值撞车的解法：/^\d+[.、)](?!\d)\s*/——"1、甲"成列表，"1.5米"不误伤（负向断言）。

4.3 配额降级链（js/store.js:34）

function persist() {
  try { storage.setItem(KEY, JSON.stringify(db)); }
  catch (e) {                    // localStorage 配额爆了：
    db.records.forEach(function (r) { r.image = null; });   // ①先弃所有图片（保全部文字）
    try { storage.setItem(KEY, JSON.stringify(db)); return; } catch (e2) {}
    /* ②丢最旧非收藏，逐条重试  ③最后从最旧丢到只剩当前一条 */
  }
}

4.4 种子抽题：确定性的"举一反三"（js/drill.js:135 / 146 / 174）

function rng(seed) {                       // mulberry32：32 位种子 PRNG
  var t = seed >>> 0;
  return function () {
    t += 0x6D2B79F5;
    var r = Math.imul(t ^ (t >>> 15), 1 | t);
    r ^= r + Math.imul(r ^ (r >>> 7), 61 | r);
    return ((r ^ (r >>> 14)) >>> 0) / 4294967296;
  };
}
function drillFor(moduleName, wrongKey, n) {
  var day = Math.floor(Date.now() / 86400000);
  var seed = day * 131 + String(wrongKey).length * 17
           + (String(wrongKey).charCodeAt(0) || 3);  // 同一天+同一错题 → 同一组
  var pool = poolMatch(moduleName);                  // 关键词 → 题池；未知 → mix
  return { pool: pool, questions: pool === 'mix'
      ? pickMix(n || 3, seed) : pick(pool, n || 3, seed) };
}

4.5 分享卡：cover 裁剪 + canvas 污染降级（js/share.js:42 / 153）

function drawCover(ctx, img, x, y, w, h) {
  var k = Math.max(w / img.width, h / img.height);   // 取较大缩放比 → 填满
  var dw = img.width * k, dh = img.height * k;
  ctx.drawImage(img, x + (w-dw)/2, y + (h-dh)/2, dw, dh); // 居中裁剪
}
// file:// 下 drawImage 本地文件会污染 canvas，toDataURL 抛错：
try { var url = canvas.toDataURL('image/png'); return { ok: true, url }; }
catch (e) {
  canvas = build(rec, parsed, null, null);           // 重画无图版照样导出
  return { ok: true, url: canvas.toDataURL('image/png'), tainted: true };
}

六、踩坑实录（编号与质检报告一致）

#现象根因 → 修复
1透明遮罩盖住整页、点击全被拦display:flex 覆盖 hidden 属性 → 全局 [hidden]{display:none !important}
2错题本移除后徽标还是旧数字计数只在建页时算 → 挪进每次渲染
3洋流图文字超出画布被裁SVG text 无居中 → text-anchor=middle + 精简
5报告页整页白屏splitSections 返回对象被当数组 .map → TypeError
6配额极限测试只剩 1 条记录降级顺序反了 → 先弃图片保文字
7导览芯片点了不滚动smooth 滚动后台被 rAF 节流 → 即时定位 + scroll-margin
9错题本点了"没反应"调了不存在的 hasKey() → ReferenceError 被事件处理器吞掉；页面注入 window.onerror 抓栈定位
共同教训：纯逻辑模块有测试 ≠ UI 接线没错——**每改一版必须 reload 后逐视图截图验收**；UI 报错被事件处理器吞掉时，用注入 window.onerror 抓栈。

老师可能追问怎么答
AI 输出格式漂移？三层兜底：提示词契约进断言；解析正则宽容兼容多种写法；失败降级原文渲染不白屏
为什么不用现成 MD 库？内容进 innerHTML 且不可信——自研"先转义后拼装"天然免疫，还有 XSS 专项断言
密钥安全？只存本机、只发用户自填端点；导出函数不含 settings，断言把关
演示模式意义？无网络可体验 + 解析器固定基准 + 离线可演示
教程与代码一致性？代码块按 文件:行号 从源文件摘录；所有数字回查质检报告与测试输出
