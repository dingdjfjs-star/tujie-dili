# 图解地理 · AI 地理图表精读工作流

**上传一张地理图表，AI 给你讲透整张图的所有地理考点。**

面向中学地理「读图难」的痛点：学生把课本/地图册里的等高线地形图、气候直方图、洋流模式图、统计图表拍照或截图上传，AI 一次完成 —— **图形要素识别 → 空间规律提取 → 教材知识点关联 → 考点易错分析 → 3 道变式题自测**，答错的题自动进错题本，还能一键「举一反三」再生成同类题、生成可分享的精读卡长图。

极简两条主线：**上传 → 精读报告**。没有角色系统、没有成就体系，单点打透多模态 AI 的专业图表理解。

功能全景（v1.2）：

- **AI 精读**：五段式教研报告（分章卡 + 章节导览 + 阅读进度条），变式题在线自测
- **错题闭环**：错题本按知识模块筛选，「举一反三」一键同类变式（AI 仿题 / 内置题池双模式）
- **精读分享卡**：一键生成带实景照片头的长图 PNG，可发同学群/家长群
- **读图自查清单**：上传前「五看」自查（图名/比例尺/图例/数值/设问），全勾亮朱砂章
- **实景照片**：首页 hero 与示例卡均为 Wikimedia Commons 自由版权实景照（署名清单随项目分发）
- **本地归档**：解析记录/错题本存本机，导出 JSON 备份，打印/下载 .md

## 快速开始

```
双击 启动.bat        → 自动打开 http://localhost:8947
或 node server.js    → 同上
或直接双击 index.html → file:// 直开亦可（全离线，仅 AI 请求需联网）
```

手机使用：电脑和手机连同一 WiFi，用启动时打印的「手机访问」地址打开，即可拍照上传课本图。

## 使用流程

1. **上传图表**：点击选图 / 拖拽 / `Ctrl+V` 粘贴截图 / 手机拍照；自动压缩到 1280px。
2. **选择年级 + 教材版本**（可选填图表类型提示），点「开始 AI 精读」。
3. **读报告**：五段结构 —— 图表基本信息 / 核心要素识别 / 规律原理讲解 / 考点与易错点 / 变式训练题。
4. **自测**：变式题在线作答（选择自动判分、主观题自判），答错自动入错题本。
5. **归档**：每份解析自动存入「图册与错题本」，可收藏、按知识模块筛选、导出 JSON 备份、打印或下载 `.md`。

## AI 配置（双模式）

| 模式 | 说明 |
|---|---|
| **演示模式（默认）** | 无需任何配置。3 张内置手绘示例图（等高线地形图 / 气温降水柱状图 / 世界洋流模式图）+ 固定精读报告，报告中明确标注「演示数据」，用于体验完整流程与离线自测 |
| **API 模式** | 右上角「AI 设置」→ 粘贴 API Key → 保存。默认智谱 **glm-4v-flash**（免费视觉模型），接口地址 OpenAI 兼容，可换 glm-4v-plus 或其他兼容多模态端点 |

- 精读提示词按立项书规范内置（五段结构 + 1200 字上限 + 禁编造），设置页可查看与复制。
- **密钥只保存在本机浏览器 localStorage**，仅随解析请求发往你自己填写的接口；导出 JSON 不含密钥。
- 常见报错：`401` 查密钥；`400` 换支持图像的模型；`429` 稍后再试；`无法连接` 查网络与接口地址。

## 数据与隐私

- 所有记录（解析 + 错题本）只存本机浏览器；容量上限 50 条，超限挤掉最旧的非收藏记录；存储配额吃紧时自动降级为「留文字、去图片」。
- 「导出 JSON」可备份 / 换机恢复；「清空全部」不可恢复。
- 图片上传前自动压缩为 JPEG（≤1280px），减少 token 消耗。

## 路线图：六个候选方向与取舍（v1.2 记录）

| # | 方向 | 判断 | 结论 |
|---|---|---|---|
| 1 | 错题举一反三（同类变式训练） | 错题本闭环的升华，教学价值与演示价值双高，API/题池双模式可行 | **✅ 已做** |
| 2 | 精读分享卡（Canvas 长图） | 传播出口，照片+纸墨风正适合出图，纯前端零依赖 | **✅ 已做** |
| 3 | 上传前读图自查清单（五看） | 零 AI 成本内化读图方法论，填平「上传前」的空档 | **✅ 已做** |
| 4 | 多图对比精读（2~4 张同主题图对比出题） | 好，但 UI 与 prompt 复杂度翻倍，留待下版 | 候选 |
| 5 | 整章批量解析（按章节批量上传生成图解集） | 依赖真实教材目录结构，演示成本高 | 候选 |
| 6 | 语音朗读讲解（Web Speech API） | 实现极简，但教学增益弱于前三者 | 候选 |

## 扩展

- **加示例图**：在 `js/samples.js` 加一条（手绘 SVG + 五段结构报告），跑 test 回归。
- **调提示词**：改 `js/prompt.js` 的 `PROMPT_TEMPLATE`（保持 `{{年级}}`/`{{教材版本}}` 占位符与五段结构），设置页展示会同步更新。
- **部署上线**：纯静态、零依赖，可走 github-pages-deploy 技能发 GitHub Pages；部署后 AI 请求由用户浏览器直连其自填接口（密钥仍在用户本地）。

## 附：ZCode 低代码平台复刻手册（三节点工作流）

本项目即「三节点线性工作流」的参考实现，可在 ZCode 低代码平台按下面的配置 1:1 搭出同款：

### 节点 1｜触发节点：图表上传启动

| 表单项 | 类型 | 必填 | 说明 |
|---|---|---|---|
| {{图表图片}} | 图片上传 | 是 | 手机拍照/相册/截图 |
| {{年级}} | 下拉 | 是 | 七年级 / 八年级 / 高一 / 高二 / 高三 |
| {{教材版本}} | 下拉 | 是 | 人教版 / 湘教版 / 中图版 / 鲁教版 / 商务星球版 / 晋教版 |
| {{图表类型}} | 下拉 | 否 | 自动识别 / 等高线地形图 / 气候图表 / 洋流图 / 统计图表 / 区域地图 / 原理示意图 / 其他 |

### 节点 2｜自动节点：AI 多模态深度解析

- 组件：多模态大模型节点，输入图片 + 文本；模型选支持图像输入的多模态模型。
- 提示词：全文见本项目「AI 设置 → 查看内置精读提示词」（或直接看 `js/prompt.js` 里的 `PROMPT_TEMPLATE`），把 `{{年级}}`/`{{教材版本}}` 绑定为节点 1 的表单变量即可。
- 参数建议：temperature 0.3，max_tokens 4096。

### 节点 3｜自动节点：结果输出与归档

- 输出页按五段结构分模块展示；「收藏」写入**个人图册错题本**表（字段：用户、图表图片、解析结果、知识模块、是否收藏、时间）。
- 解析原文写入**图表解析记录表**（字段：用户、图片、解析结果、年级、教材版本、时间），支持导出。

### 数据表（2 张）

1. **图表解析记录表**：id、用户、图片、解析结果、年级、教材版本、知识模块、来源（AI/演示）、时间。
2. **个人图册错题本**：id、用户、关联解析 id、题号、题干、是否掌握、时间。

## 简历写法（直接复用）

**项目名称：基于多模态大模型的地理图表智能精读工具**

**项目描述：** 针对中学地理读图教学痛点，搭建地理图表 AI 深度解析工作流，融合多模态大模型与地理学科知识，实现各类地理图表的自动要素识别、规律提炼、考点分析与智能出题，打造轻量化地理读图学习工具。

**核心工作：**
1. 设计并实现「上传-解析-输出」三段式工作流，完成全流程配置与联调；
2. 优化多模态大模型地理专业图表解析 Prompt，实现等高线、气候图等多类图表的结构化理解（五段式教研报告：要素识别/规律讲解/考点易错/变式出题）；
3. 构建对应中学课标的知识点与考点映射，配套变式题自测与错题本闭环（选择自动判分、主观自判、答对自动移出）；
4. 实现本地归档与隐私保护方案（密钥仅存本地、导出不含凭据、存储配额自动降级），配套自动化质检（191 项断言）。

**技术栈：** 多模态大模型（GLM-4V）、OpenAI 兼容 API、工作流引擎、零依赖原生 JS/Node、localStorage 数据工程
